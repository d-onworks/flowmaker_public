# 소재 찾기와 사실 검증

## 1. 좋은 소재의 조건 — 넷 다 맞아야 한다

1. **아는 것이어야 한다.** 상위 조회 영상에 완전 무명 장소는 하나도 없었다. 유명 건축물·일상 사물·교과서에 나오는 것.
2. **통념을 뒤집는 한 줄이 있다.** "머리만 있는 게 아니었다" "들어올리는 게 아니라 기울인다" "얼음이 아니라 물을 상대했다".
   이 한 줄이 없으면 만들지 않는다.
3. **단면으로 설명된다.** 겉에서 안 보이는 구조·힘·흐름이 있어서 잘라 보여줘야 이해되는 것. 회색 점토 다이어그램이 무기가 되는 지점.
4. **엔딩 숫자가 있다.** 최초 연도 + 지금도 쓰인다는 사실 + 누적 수혜(살린 사람 수·설치 대수·지켜온 햇수).

`topics.md` 에 이 조건으로 걸러둔 씨앗 30개가 있다.

## 2. 후보 제시 형식 (사용자에게)

```
1. 타워브리지 도개교 — "1,200톤을 들어올리는 게 아니라 기울인다" · 검증 쉬움(공식 사이트에 수치) · 예시 있음
2. 콜로세움 지하 승강기 — "검투사와 맹수가 바닥에서 솟아올랐다" · 검증 보통(고고학 논문)
3. …
```
반전 한 줄 · 검증 난이도 · 비슷한 예시 유무. 3~5개. 고르면 3절로.

## 3. 사실 검증 절차 → `facts.md`

대외 공개물이다. **지어낸 숫자 하나가 채널 신뢰를 끝낸다.**

1. **1차 자료부터.** 운영 기관 공식 페이지 · 논문(DOI) · 정부 기록 · 박물관. 블로그·위키는 출발점일 뿐 출처가 아니다.
2. **수치는 두 출처로 교차.** 자료마다 다르면 보수적인 쪽("7,700명 이상"). 합쳐지지 않으면 대본에서 뺀다.
3. **엔딩 숫자를 반드시 찾는다.** 최초 연도, 지금도 쓰이는 근거, 누적 숫자. 없으면 대체 지표(설치 대수·표준 채택 연도).
4. **"쓰면 안 되는 것"을 적는다.** 통설이지만 근거 없는 것(예: "석상 270톤"), 최근 정정된 것, 논쟁 중인 것.
5. **조사 못 한 것도 적는다.** 정직하게.

`facts.md` 형식 (예시 폴더의 것을 그대로 따른다):
```
# [소재] — 사실 검증
## 1. 구조 원리         (대본이 말하는 원리, 출처)
## 2. 연도와 실물        (언제, 어디, 몇 개가 남았나)
## 3. ★언제 시작됐나     (엔딩 킥 1)
## 4. ★누구에게 갔나     (엔딩 킥 3 — 사람 숫자)
## 5. 실측 수치          (대본에 쓸 수치와 일상 단위 환산)
## 6. ★쓰면 안 되는 것
## 조사 못 한 것
```

## 4. 대본으로 넘어가기 전 확인

- 훅 첫 문장에 숫자가 없는가
- 질문형이 딱 한 번(거짓 해결책)인가
- "발상을 뒤집습니다"(또는 같은 기능의 문장)가 52~62% 지점에 있는가
- 큰 수가 일상 단위로 한 번 이상 환산됐는가
- 엔딩에 연도 + 현재형 + 숫자가 있는가
- 25~30문장, 공백 제외 500~650자인가
