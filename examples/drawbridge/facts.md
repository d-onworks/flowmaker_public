# 「도개교 — 끊어야 지나가는 다리」 사실 검증

## 0. ★검증이 축을 뒤집었다 (착수 전 가설이 틀렸다)

내가 세운 축은 **"균형추가 다리 무게와 거의 같아서 사람 힘으로 열린다"** 였다. **틀렸다.**
- 타워브리지 배스큘 한 짝 **1,000~1,200톤** vs 균형추 **400톤** — 3분의 1 수준이다.
- 게다가 일부러 **다리 쪽을 더 무겁게(span-heavy)** 설계한다. 그래야 힘을 안 줘도 중력으로 닫힌 채 버틴다.

**성립하는 진짜 원리 = 무게가 아니라 모멘트(무게 × 회전축까지의 거리)가 맞선다.**
출처: [heavymovablestructures.org 학회자료](https://heavymovablestructures.org/wp-content/uploads/2017/12/64.pdf)
(원문 예시: 축에서 50피트 지점에 500파운드를 더하면 균형추 1,250파운드가 필요하다 → 25,000 대 25,000)

**★뺀 것 — 균형추가 축에 "가까운지 먼지"는 쓰지 않는다.** 조사 요약은 "가까이 붙어 있다"고 했지만
위 산술(400톤이 1,200톤과 맞서려면 거리가 3배여야 한다)과 어긋난다. 어느 쪽인지 1차 자료로
확정하지 못했으므로 **방향을 말하지 않고 "무게 곱하기 거리가 맞아떨어진다"까지만 쓴다.**

## 1. 구조 원리

- **확정 — 어원**: bascule = 프랑스어 "시소·저울". 중심을 벗어난 회전축으로 시소처럼 움직인다.
  출처: [towerbridge.org.uk — how it works](https://www.towerbridge.org.uk/stories/how-does-tower-bridge-work)
- **확정 — 모멘트 균형**: 리프는 짧은 팔(heel, 뭍 쪽)과 긴 팔(toe, 강 쪽)로 나뉘고, heel에 균형추를 달아
  toe의 모멘트를 상쇄한다.
- **확정 — 동력 절감**: 균형이 거의 맞으면 구동부가 이겨야 할 힘은 마찰 수준으로 줄어 **작은 모터로 충분**하다.
  출처: [EngineerFix](https://engineerfix.com/how-does-a-bascule-bridge-work/)
- **확정 — span-heavy 설계**: 일부러 다리 쪽을 조금 더 무겁게 해 무동력으로 닫힌 상태를 유지한다.
- **확정 — 잠금 = 노즈 볼트**: 닫히면 **길이 2m 볼트 4개**가 밀려 나와 도로면을 고정한다.
  2023년 10월 1970년대 이후 처음 전면 교체. 출처: [Construction Management](https://constructionmanagement.co.uk/video-tower-bridges-2m-long-nose-bolts-replaced/)
- **확정 — 여는 순서(증기 시대)**: 벨 신호 → 경찰이 교통 차단 → 스토핑 블록 후진·노즈 볼트 인출 →
  시동 밸브 → 브레이크로 정지. 출처: [towerbridge.me.uk](https://towerbridge.me.uk/original-machinery/)
  **주의**: 현행 전기유압 절차 원문은 못 찾음.
- **뺀 것**: 트러니언이 받는 하중(톤) 수치 — 확인 못 함.

## 2. 타워브리지 (1894)

| 항목 | 값 | 비고 |
|---|---|---|
| 건설 | 1886~1894 (8년) · 개통 1894.6.30 | |
| 설계 | 건축가 호레이스 존스 · 엔지니어 존 울프 배리 | 존스는 1887년 사망 |
| 배스큘 한 짝 | **1,000~1,200톤** | 출처마다 다름 — "1,200톤이 넘는다"가 최다 인용 |
| 균형추 | **400톤** | |
| 배스큘 챔버 | 폭21m×길이59m×높이27m | |
| 동력 | 증기 유압 + 축압기 6기 → **1976년 전기유압 전환** | |
| 개방 빈도 | 개통 첫해 연 6,160회 → 현재 연 **약 850회** | ⚠ 1차 URL 특정 실패 |

- **★확정 — 배 우선권은 법적 의무**: 1885년 Corporation of London (Tower Bridge) Act에 따라
  마스트·상부구조 **9m 이상** 선박이 요청하면 시가 **무료로** 열어줘야 한다. **24시간 전 통보**, 연중무휴.
  출처: [towerbridge.org.uk — request a bridge lift](https://www.towerbridge.org.uk/bridge-lifts/request-a-bridge-lift)
- **주의 — 개방 각도**: 82/83/86도로 갈린다 → **각도는 대본에서 뺀다.**
- **주의 — "5분"**: 원문은 "닫혀서 통행 재개까지 5분"이지 "여는 시간"이 아니다 → **뺀다.**

## 3. 언제 시작됐나

- **확정 — 근대 배스큘은 1890년대**: 1893년 시카고 밴뷰런교(셔처 특허) → 1894년 타워브리지 →
  1902년 시카고 코틀랜드교(고정 트러니언, 이른바 시카고식).
  출처: [StructureMag](https://www.structuremag.org/article/joseph-b-strauss-bascule-bridge/) · [Cortland Street Drawbridge](https://en.wikipedia.org/wiki/Cortland_Street_Drawbridge)
- **★쓰면 안 됨 — "고대부터 있었다"**: 고대에 있던 건 지렛대+평형추 **원리**(이집트 샤두프)이지 다리가 아니다.
- **주의 — 중세 성 도개교**: 대부분 체인·윈들러스 방식. 균형추식은 "일부 후기"만 → 일반화 금지.

## 5. ★쓰면 안 되는 것

1. **"균형추 무게가 다리와 같다"** — 1,200 vs 400톤. **모멘트가 같다**로 써야 한다.
2. **균형추가 축에 "가깝다/멀다"** — 산술과 조사 요약이 충돌. 방향은 쓰지 않는다.
3. **개방 각도 단일 수치** — 82/83/86도로 갈린다. 뺀다.
4. **"여는 데 5분"** — 원문은 "닫혀서 통행 재개까지". 뺀다.
5. **"영도대교가 매일 열린다"** — 틀렸다. 주 1회(토요일).
6. **"배스큘이 고대부터"** — 원리만 고대. 다리는 1890년대.
7. **축압기 세부 수치(20인치·35피트·5분37초)** — 비공식 사이트 1곳뿐. 뺀다.
8. **전 세계 배스큘 총 개수** — 통계 없음. 시카고 44개 중 12개 미운영만 확정.
